⚙ Connect Google Sheets

Link a Google Sheet to keep the dashboard updated automatically. Anyone who can edit the sheet can update charts and notes without touching code.

1
Create a Google Sheet and set sharing to "Anyone with the link can view"
2
Create these tabs (exact names):

Steam   → paste Steam CSV (skip first 2 rows)
Meta    → paste Meta Quest CSV
Sales   → date | orders | revenue_usd
Discord → date | total_joins
Events  → date_start | date_end | title | description
Notes   → week_date | note
Milestones → name | date_start | date_end
3
Copy the Sheet ID from the URL:
docs.google.com/spreadsheets/d/SHEET_ID_HERE/edit
4
Paste it below and click Connect.
Found in the Google Sheets URL between /d/ and /edit
Will be replaced by the Notes tab value when connected to Sheets.
